## 2. Data Analysis with PartyRock

An AI-assisted environmental data analysis project developed using Amazon PartyRock and the OpenAQ air quality dataset.

The project demonstrates how generative AI can assist with:

- Dataset exploration
- Statistical analysis
- Trend identification
- Pollution pattern analysis
- Correlation analysis
- AI-assisted interpretation
- Structured analytical reporting
- Environmental data observations

### Key Analysis Areas

- Pollutant concentration analysis
- Time-series trend analysis
- Peak pollution identification
- Correlation analysis between pollutants
- Statistical summary generation
- Environmental pattern interpretation
- AI-generated environmental reporting

### Dataset Used

**OpenAQ Air Quality Dataset (Del Norte, New Mexico)**

The dataset includes environmental air quality measurements for:

- PM10
- PM2.5
- Ozone (O3)
- Carbon Monoxide (CO)
- Nitrogen Dioxide (NO2)
- Sulfur Dioxide (SO2)

### Included Deliverables

- Original dataset
- AI-generated analysis outputs
- Correlation analysis outputs
- Consolidated Excel analysis report
- Final PDF environmental report
- Prompt documentation
- Workflow screenshots
