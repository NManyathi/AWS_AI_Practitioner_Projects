# Project Overview

This project is an AI-powered productivity assistant designed to help users improve focus, manage priorities, reduce distractions, and build sustainable productivity habits through structured AI-assisted coaching workflows.

The system uses reusable prompts and AI-guided productivity strategies to generate personalized action plans, focus recommendations, and reflection-based improvement suggestions.

# Example Prompts Used

## Daily Action Plan Prompt

```text
Create a structured productivity plan for today based on my goals, priorities, and available time.
```

---

## Motivation and Focus Prompt

```text
Help me stay motivated and focused while working on my most important tasks today.
```

---

## Distraction Defense Prompt

```text
What strategies can I use to avoid distractions and remain productive during my work session?
```

---

## Weekly Reflection Prompt

```text
Help me reflect on my productivity habits this week and identify areas for improvement.
```
